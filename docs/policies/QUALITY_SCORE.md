# QUALITY_SCORE — PR 품질 점수 체계

> 자동 산출되는 점수. 자율성 승격·강등의 입력으로 쓴다.

## 구성 (0–1, 가중합)
| 항목 | 가중 | 산출 |
|------|------|------|
| verify.sh 통과 | 0.25 | 통과 1, 실패 후 재시도 성공 0.5, 실패 0 |
| 테스트 추가 비율 | 0.15 | 변경 LOC 대비 추가 테스트 LOC ≥ 0.5 일 때 1 |
| 구조 위반 | 0.15 | 0건 1, 1건 0.5, 2+건 0 |
| PR 크기 | 0.10 | ≤ 400 LOC 1, 800 0.5, 그 이상 0 |
| 자기 리뷰 코멘트 | 0.05 | 작성 1, 없음 0 |
| 문서 갱신 | 0.10 | 관련 product-specs/exec-plans 갱신 시 1 |
| UI 회귀 결과 | 0.10 | 시나리오 전체 pass 1, 실패 0 |
| 관측 지표 리포트 첨부 | 0.10 | 첨부 1, 없음 0 |

## 집계
- `scripts/quality-score.py`가 PR별로 계산해 라벨과 코멘트 생성.
- 주간 요약은 `docs/generated/quality/score.md`.

## 임계치
- 병합 최소: ≥ 0.6
- 자동 머지 자격(cleanup only): ≥ 0.9 + 분류 `cleanup`
- 2주 평균 ≥ 0.9 → 자율성 한 단계 승격 후보

## 가중치 변경
- 분기 1회 리뷰. PR로만 수정, 사람 승인 1인.
